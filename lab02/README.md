# Books Dataset

Used a CSV dataset of books for a Recombee recommendation system. The dataset contains **6,810 book items**.

## Recombee Item Properties

| Property         | Type     | Description                 |
| ---------------- | -------- | --------------------------- |
| `title`          | `string` | Book title                  |
| `subtitle`       | `string` | Book subtitle               |
| `authors`        | `string` | Author or authors           |
| `categories`     | `string` | Book category or genre      |
| `description`    | `string` | Book description            |
| `published_year` | `int`    | Publication year            |
| `average_rating` | `double` | Average user rating         |
| `num_pages`      | `int`    | Number of pages             |
| `ratings_count`  | `int`    | Number of ratings           |
| `thumbnail`      | `string` | URL of the book cover image |

Dataset link: https://www.kaggle.com/code/abdallahwagih/books-recommendation-system
